Comprehensive audit of OpenLIA against the newest design, covering every page, multi-user readiness, report generation, report rendering, LLM instructions, portfolio, and open-source release readiness. Produced by 7 parallel deep-read audits; every claim carries file:line evidence in the source reports. This document is the staged remediation plan.

**How to use this document:** each stage is self-contained and executable in a fresh session. Work stages in order — Stage 0 is urgent, later stages depend on earlier ones (Stage 0 restores CI signal that every later stage's verification needs). Items marked `DECISION` need a product call before implementation. Verification steps are listed per stage; do not mark a stage done without running them.

**Baseline caveat:** `pytest` has not run in CI since 2026-08-09 (blocked by a ruff-format gate), so backend test health on `main` is currently unverified. Stage 0 re-establishes the baseline before anything else is trusted.
