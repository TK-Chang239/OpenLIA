# Morning Briefings Department Spec

## Page Overview
The morning briefings department generates a morning briefings report every morning at a set time determined by the user. The user can decide what sections and topics to be covered in the reports, from which countires to cover to what types of markets and specific tickers.
Whenever the reports are completed, MB will notify the user through email.

## Functionalities
1. **Morning Briefings Report**: Every morning at the user determined time MB will generate a morning briefings report to summarize news of topics and sections in the Covearge List.
2. **Coverage List**: The user can edit the Coverage List to add or remove topics that the user wants to be covered in the Morning Briefings report. The sections in the reports are fixed, but under each section the user can add or remove topics he wants to be covered in the report by typing in the textbox and clicking add. The user is also able to check or uncheck sections to decide what sections should be covered and what sections should not. See "Report Sections" below for more.
3. **Report Schedules**: The user can choose what time to the morning briefing reports should be generated by, such as the exact time, time zone, and days of the week, The user can set more than one time per day, such as both a pre-market breifing and a post-market briefing.

## User Interface Design

### Overview

The Morning Briefings page has two views that share the same page header:
- **Archive View** (default): A chronological grid of generated report cards.
- **Settings View**: A configuration panel for report sections and schedules. Accessed via the Settings button; returns to Archive via a Back button.

There is no modal — clicking Settings switches the full content area.

## Page Settings
### Report Sections
The reports sections are fixed, meaning that the user will not be able to edit or remove these sections. What the user can do is check or uncheck sections to decide what sections should be covered and what sections should not. 

What the user will be editing is the topics to be covered under each section. The user will be able to type and add keywords he would like to be covered under each section. In addition, if the user wants to add a custom section that is also possible with the custom sections part. The user can add multiple custom sections.

The default sections and what the user can change are:
1. Executive Summary
- A summary of each morning briefing.
- User Options: The user can only check or uncheck this section, but can not add any key words.
2. Global Macro News
- A summary of important news around the world. Covers the biggest events around the world.
- User Options: In addition to the biggest events around the world, the user can add more specific topics to this section, such as war, politics, energy, etc.
- Cross-reference: MB calls `MacroResearchDepartment.get_current_snapshot(user_id)` (see `planning/specs/systems/macro-research-dalio-dashboards-design.md` § Public API for Cross-Department Consumers) to read MR's current framework statuses (debt cycle phase, current economic season, active force count) and inject them as macro context. If the returned `MRSnapshot` has `is_stale=True` or all fields are `None`, MB skips the macro-context block rather than embedding outdated or empty data.
3. Country News
- Covers main news of a country. Will cover specific topics in greater detail if specified by user under advanced options.
- User Options: The user can add countries to this list, such as US, Taiwan, Japan, Korea, etc. The report will only cover news of countries that are in this list. 
4. Market News
- Covers main news of specific markets.
- User Options: The user can add markets, such as bond markets, gold markets, etc. to the list. The report will only cover markets that are in this list.
5. Sector News
- Covers main news of specific sectors or industries
- User Options: The user can add sectors or industries to this list. The report will only cover sectors or industries that are in this list.
6. Stock News.
- Covers main news of specific stocks or companies.
- User Options: The user can add stocks or companies to this list. The report will only cover stocks that are in this list.
7. Upcoming Preview
- Provides a summary and preview of the major upcoming events.
- User Options: The user can specify any topics to be covered in this section.
- Advanced Options: The user can check "Reference Portfolio" options so that MB will reference the user Portfolio to identify topics to be covered.
8. Custom Sections
-  This section allows the user can add customized sections, with a box to include a description for more context on what to cover in these sections.

### Report Schedules
The user can choose what time to the morning briefing reports should be generated by, such as the exact time, time zone, and days of the week, The user can set more than one schedule per day, such as have MB generate both a pre-market breifing and a post-market briefing in the same day.

## Report Framework

| File | Path |
|---|---|
| Framework JSON | `packages/core/src/openlia/reports/frameworks/morning_briefing.json` |
| Style Guide | `packages/core/src/openlia/reports/frameworks/morning_briefing_style_guide.md` |

The Morning Briefing has a single report mode: `morning_briefing`. The 7 standard sections (Executive Summary, Global Macro, Country News, Market News, Sector News, Stock News, Upcoming Preview) are fixed in the framework, but the user configures which sections are active and what topics appear under each section via the Settings View. The server-side template builder strips unchecked sections and injects user-configured topics into the section instructions before passing the framework to the LLM.

Custom Sections defined by the user are appended after the standard sections. Each custom section's user-provided description is used as the LLM instruction.

## Data Requirements

MB uses pre-fetch to gather news and events before passing to the LLM for report generation.

**Basic (department disabled without these):**

| Requirement | Type | Description |
|---|---|---|
| Company news | `company_news` | News articles across all configured topics (macro, country, market, sector, stock) |
| Economic events | `economic_events` | Economic calendar events for Upcoming Preview section and macro context |

**Advanced (features degrade gracefully if missing):**

| Requirement | Type | Description | Without It |
|---|---|---|---|
| Stock quote | `stock_quote` | Current prices for tickers in Stock News section | Stock News section lacks current price context |
| Historical prices | `historical_prices` | Recent price data for market and sector trend context | Market News and Sector News sections lack quantitative price trend data |
| Macro indicators | `macro_indicators` | Macroeconomic data (GDP, CPI, rates) for Global Macro section | Global Macro News section relies solely on news articles without quantitative macro data |
