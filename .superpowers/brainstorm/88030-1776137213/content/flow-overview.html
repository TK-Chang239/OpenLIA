Setup Wizard — full flow

Five linear steps, with a hub in step 4. Entry condition: personal mode, first launch (no completed wizard record in DB). Env vars don't block the wizard; they appear as read-only pre-filled values.

1
Welcome
One-screen intro. Explains the 4 upcoming steps and what keys to have ready. Single 'Get started' button.
›
2
Identity
Display name only. Used by departments when addressing user.
›
3
AI Models
Primary model + Review model. Two slots, same-provider default. Ping on save.
›
4
Data Providers
Sidebar tabs: Financial, News, Social. Hub per tab with ordered list + 'Add' (panel takeover). Ping on save per provider.
›
5
Review
Auto-runs AI mapping. 2-col grid of department readiness cards. Finish enables if all basic reqs met.
Cross-cutting:
  • Env precedence: All steps appear; env-set fields render read-only with 'from environment' badge.
  • Resume: Server persists progress after each step. Reopening wizard returns to the last completed step.
  • Validation: Ping test on every key save; green/red inline feedback.
  • Completion gate: User cannot finish unless Review reports all basic requirements met for required departments.
