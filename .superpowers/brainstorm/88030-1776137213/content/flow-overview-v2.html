Cross-cutting (both paths):
  • Mode detection: OPENLIA_MODE env var (personal | company) wins if set; otherwise picked in step 1.
  • Env precedence: env-set fields render read-only with an 'inherited from environment' badge.
  • Resume: server persists progress after each step; reopening the wizard returns to last incomplete step.
  • Validation: ping test on every key save \u2014 inline green/red feedback.
  • Completion gate: can't finish unless all basic requirements met for required departments.
