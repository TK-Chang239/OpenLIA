Key layout elements:
  • Page header (56px) -- matches all other departments. Auto-refresh dropdown + Settings button.
  • Summary strip -- one status badge per dashboard, always visible. Shows the headline verdict from each framework at a glance.
  • Tab bar -- five tabs: Debt Cycle, Four Seasons, All-Weather, World Order, Five Forces. Active tab has underline accent.
  • Dashboard content -- each tab shows a full dashboard. T1 shown here as example with scorecard, phase assessment, monetary policy space, and watchlist triggers.
