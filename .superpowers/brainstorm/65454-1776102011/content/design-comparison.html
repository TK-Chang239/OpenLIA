Macro Research: Design Comparison

Other agent's template system vs. our evolving dashboard design

Other Agent's Design: "Template System"

Strengths
  • Cross-template dependency graph -- T1, T2, T4 feed into T5; T5 feeds into T3. Execution order enforced.
  • Polished visual design system -- shared color semantics (red/amber/green/blue/purple), badge components, card hierarchy, scorecard tables.
  • T3 as portfolio audit -- compares user's portfolio against All-Weather targets (coverage map, risk parity, gold gap).
  • Reinforcement loop analysis in T5 -- identifies feedback loops between forces.
  • Historical analogs in T4 -- requires both "Similar" and "Different" to resist lazy analogizing.
  • Synthesis verdicts with downstream consumption notes per template.
Weaknesses
  • Static reports, not live dashboards -- hardcoded April 2026 data. No auto-refresh.
  • No user-configurable thresholds -- Dalio's warning zones are baked in, not editable.
  • Standalone HTML files -- not integrated into OpenLIA's three-layer architecture.
  • Every refresh requires a full LLM run -- expensive for indicators that are just numbers.
  • No formula engine -- threshold evaluation is narrative, not programmatic.

Our Design Direction

Strengths
  • Live-updating dashboards -- auto-refresh with configurable intervals.
  • Formula engine for T1 & T2 -- user-configurable thresholds via Panic Thermometer DSL. Fast, deterministic, no LLM cost.
  • LLM assessment for T4 & T5 -- qualitative frameworks get proper narrative interpretation.
  • Integrated into OpenLIA -- fits the three-layer architecture (core/server/frontend).
  • Pre-fetch data pattern -- code fetches data, formula engine or LLM evaluates. Clear separation.
What We Were Missing
  • Cross-dashboard dependencies -- T5 needs T1/T2/T4 outputs; T3 needs T1/T2/T5.
  • T3 as portfolio audit -- much richer than just displaying All-Weather weights.
  • Visual design system -- the other agent's color semantics and component patterns are excellent.
  • Execution ordering for LLM assessments -- can't run T5 before T1 and T4.

The Combined Design

Adopt the other agent's visual design system, cross-template dependency graph, and T3 portfolio audit concept. Combine with our live data refresh, formula engine for T1/T2, periodic LLM assessment for T4/T5, and OpenLIA integration.
